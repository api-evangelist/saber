# Saber

> Saber is a decentralized automated market maker (AMM) on the Solana blockchain, optimized for trading and providing liquidity between mean-reverting assets such as stablecoins and wrapped/pegged tokens. Rather than a REST API, Saber exposes its functionality as an on-chain program (StableSwap) plus first-party TypeScript SDKs and Rust crates that build and submit Solana transactions.

## Product
- StableSwap AMM: low-slippage swaps between pegged assets (USDC/USDT, wrapped assets, etc.)
- Liquidity provision and LP tokens
- On-chain governance and asset registry

## Notes for agents
- There is no HTTP/REST or OpenAPI surface; integrate via the on-chain program using the SDKs above.
- No public /.well-known/ discovery documents are published (the app host serves an SPA shell for all paths).
